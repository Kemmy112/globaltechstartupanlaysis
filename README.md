Global Tech Startup Analysis
Project Overview

This project analyses global tech startups and their progress across different stages of growth, from Seed and Early Stage to Post-IPO.

The analysis explores startup performance, funding, valuation, revenue, workforce changes, AI adoption, and other key indicators to understand how tech companies evolve as they move through different stages of growth.

Tools Used
Microsoft Excel — Data cleaning, transformation, and preparation
Power BI — Data visualization, dashboard development, and analysis\

Data Cleaning

Microsoft Excel was used to prepare the dataset for analysis. This included:

Removing duplicate and irrelevant records
Handling missing values
Standardizing data formats
Cleaning categorical fields
Checking data consistency
Preparing the dataset for Power BI
Data Visualization

The cleaned dataset was imported into Power BI, where interactive dashboards were created to explore startup performance and identify patterns across different stages of growth.

The dashboard provides an overview of key startup metrics and allows users to compare companies based on factors such as funding, valuation, revenue, workforce, and growth stage.

Key Questions

The analysis seeks to answer questions such as:

1. How does startup performance change across different growth stages?
2. Which stages attract the most funding?
3. How does valuation vary from Seed-stage startups to Post-IPO companies?
4. What patterns can be observed in revenue and ARR?
5. How do employee growth and layoffs differ across startup stages?
6. How does AI adoption vary among global tech startups?
7. What characteristics are associated with more mature and successful startups?
